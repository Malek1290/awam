# المقاس الخاص = الرقم اللي العميل بيكتبه

> **التاريخ:** 31 أكتوبر 2026
> **الاختبارات:** **109 ✅ / 0 ❌** (85 للموقع + 24 للبيانات)

---

## اللي اتغيّر

قبل كده لما العميل يختار شريحة **«مقاس خاص»** ويكتب رقم، كان بيتحفظ كـ:

```
مقاس خاص · 42
```

دلوقتي بقى بيتحفظ ويظهر **الرقم بس**:

```
42
```

كلمة «مقاس خاص» بقت مجرد **شريحة** بتفتح خانة الرقم — مش جزء من اسم المقاس.

---

## إيه اللي بيظهر فين

| المكان | الشكل |
|---|---|
| تحت شرائح المقاس في صفحة المنتج | `42` |
| درج السلة (اللي بيفتح من زرار السلة) | `مقاس 42` |
| صفحة السلة | `المقاس: 42` |
| ملخص الطلب في صفحة الدفع | `مقاس 42` |
| رسالة الواتساب | `المقاس: 42` |
| الطلب المحفوظ (`orders.items[].size`) | `42` |
| لوحة التحكم → تاب الطلبات | `مقاس 42` |

المقاسات العادية زي ما هي: `مقاس M` · `مقاس L` · `مقاس FREE SIZE`.

---

## لو العميل ما كتبش رقم؟

- زر «أضف إلى السلة» بيقفل العملية ويطلب منه يكتب رقم (من 30 لـ 70).
- الرقم برّه المدى (زي 20 أو 200) مرفوض.
- لو مفيش رقم خالص، بيتحفظ اسم الشريحة «مقاس خاص» (حالة نادرة جدًا — مش بيحصل من الواجهة).

---

## السلال والطلبات القديمة

أي حاجة محفوظة بالشكل القديم `مقاس خاص · 42`:

- **بتتعرض كـ `مقاس 42`** على طول (من غير ما تتعدّل).
- **ولو اتعملت طلب جديد**، بتتحفظ في الطلب كـ `42` النضيف.

يعني مفيش داعي تعمل أي حاجة للسلال القديمة.

---

## التفاصيل التقنية

في `assets/js/core.js`:

| الدالة | وظيفتها |
|---|---|
| `util.isCustomLabel(x)` | هل ده اسم الشريحة نفسها؟ (`مقاس خاص` / `مقاس مخصص` / `custom`) |
| `util.customSizeNumber(x)` | بيطلّع الرقم من `42` أو من القديم `مقاس خاص · 42` |
| `util.isCustomSize(x)` | شريحة **أو** رقم مقاس خاص |
| `util.composeSize(label, value)` | `(مقاس خاص, 42)` → `42` |
| `util.sizeText(x)` | النص اللي بيتحفظ: `42` / `M` / `مقاس خاص` |
| `util.sizeLine(x)` | السطر اللي بيتعرض: `مقاس 42` / `مقاس M` / `مقاس خاص` |

الملفات اللي بتعرض المقاس: `core.js` (درج السلة + الواتساب + العرض السريع) · `product.page.js` · `cart.page.js` · `checkout.page.js` · `admin.js`.

## الاختبارات المضافة (9)

| # | الاختبار |
|---|---|
| 1 | `composeSize` بيرجّع الرقم بس (`42`)، ولما مفيش رقم بيرجّع اسم الشريحة |
| 2 | `sizeText` / `sizeLine` بيعرضوا `42` / `مقاس 42` صح |
| 3 | الشريحة «مقاس خاص» بتفضل شريحة، والرقم بيتحسب مقاس خاص |
| 4 | رسالة الواتساب فيها `المقاس: 42` بس |
| 5 | صفحة المنتج: `#sizeHint` = `42` والسلة بتخزّن `42` |
| 6 | درج السلة بيعرض `مقاس 42` (من غير «مقاس خاص») |
| 7 | السلة القديمة `مقاس خاص · 42` بتتعرض `مقاس 42` |
| 8 | صفحة السلة بتعرض `المقاس: 42` |
| 9 | الشيك آوت: الملخص `مقاس 42` + الطلب بيتحفظ `size: '42'` |

+ اختبار في لوحة التحكم إن الطلبات بتعرض `مقاس 42`.

## فحص شامل للموقع (جديد في نفس التحديث)

اتضافت مجموعة **«10) فحص شامل لكل صفحات الموقع»**:

1. كل صفحة من الخمس بتفتح **من غير أي خطأ JS** + العنوان بالاسم الجديد + الهيدر والفوتر موجودين.
2. مفيش أي رابط داخلي بيشاور على صفحة مش موجودة.
3. مفيش `localhost` ولا `127.0.0.1` في أي صفحة.
4. مفيش أخطاء (`TypeError` / `ReferenceError`) في الكونسول أثناء التنقل.
5. **لو قاعدة البيانات وقعت**: الرئيسية والمتجر بيعرضوا منتجات العرض، والسلة والدفع بيحسبوا الشحن من القيم الافتراضية — كل ده من غير أي خطأ.
