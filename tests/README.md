# اختبارات عوام الدلنجات

بتشتغل على **الموقع نفسه**: سيرفر محلي + DOM حقيقي (jsdom) + سكربتات الموقع بتتنفّذ فعلًا، وSupabase متستبدل بـ mock بيرجّع نفس شكل البيانات الحقيقي.

## التشغيل

```bash
cd tests
npm install
npm test
```

## إيه اللي بيتاخد باله

- `harness.mjs` — سيرفر استاتيك + تجهيز الصفحة + mock لـ `fetch` + بيانات تجريبية (منتج فيه مقاس ولون نافد، منتج نافد بالكامل، منتجات بأقسام قديمة…).
- `site.test.mjs` — الـ 62 اختبار.

> `node_modules` مش بيتحفظ في الريبو (شوف `.gitignore`) — `npm install` بيعملها عندك.
