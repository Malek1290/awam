# اختبارات عوام الدلنجات

بتشتغل على **الموقع نفسه**: سيرفر محلي + DOM حقيقي (jsdom) + سكربتات الموقع بتتنفّذ فعلًا، وSupabase متستبدل بـ mock بيرجّع نفس شكل البيانات الحقيقي.

## التشغيل

```bash
cd tests
npm install
npm test
```

## إيه اللي بيتاخد باله

- `harness.mjs` — سيرفر استاتيك + تجهيز الصفحة + mock لـ `fetch` + بيانات تجريبية (منتج فيه مقاس ولون نافد، منتج نافد بالكامل، منتجات بأقسام قديمة، طلبات وكوبونات وإعدادات في نفس الجدول…).
- `site.test.mjs` — **68 اختبار** للموقع نفسه (الرئيسية · المتجر · صفحة المنتج · المقاس الخاص · السلة · الشيك آوت · لوحة التحكم · الأداء).
- `data.test.mjs` — **24 اختبار** لموديل البيانات: كل حاجة في `awam-data` (منتجات/طلبات/كوبونات/إعدادات) + الـ RLS + ملف الـ SQL + **صفر طلبات على أي جدول تاني**.

**الإجمالي: 92 اختبار.**

> `node_modules` مش بيتحفظ في الريبو (شوف `.gitignore`) — `npm install` بيعملها عندك.
